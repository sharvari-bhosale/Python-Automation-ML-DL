Online Bookstore Management System 📚

📌 Project Overview

The Online Bookstore Management System is a SQL-based project developed using PostgreSQL to manage bookstore information, including books, customers, and orders. This project demonstrates SQL querying skills and database concepts through basic and advanced business-related queries.

🛠️ Technologies Used

- PostgreSQL
- SQL
- pgAdmin (for writing and executing queries)

🗂️ Database Tables

The project contains three tables:

1. Books — stores book titles, authors, genres, publication years, prices, and stock quantities.
2. Customers — stores customer names, email addresses, phone numbers, cities, and countries.
3. Orders — stores customer orders, book IDs, order dates, quantities, and total amounts.

🎯 Project Objectives

- Retrieve and filter book information.
- Manage and analyse customer and order records.
- Calculate total stock and sales revenue.
- Identify the most expensive and lowest-stock books.
- Analyse genre-wise sales and average book prices.
- Identify frequent customers and popular books.
- Calculate customer spending and remaining inventory.

💻 SQL Concepts Covered

- CREATE TABLE and DROP TABLE
- SELECT, WHERE, ORDER BY, and LIMIT
- DISTINCT and BETWEEN
- Aggregate functions: SUM(), COUNT(), AVG()
- JOIN operations
- GROUP BY and HAVING
- Primary keys and foreign keys
- CRUD operations and relational database concepts

▶️ How to Run the Project

1. Install PostgreSQL and open pgAdmin or another PostgreSQL client.
2. Create a practice database.
3. Open the "online_bookstore.sql" file in the SQL editor.
4. Review the script before execution because it drops and recreates the project tables.
5. Execute the script to create the tables and run the example queries.
6. Insert sample records into the tables before running the queries if you want to see meaningful query results.

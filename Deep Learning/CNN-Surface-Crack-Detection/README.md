# Industrial Surface Crack Detection Using CNN

## Project Overview

This project focuses on detecting industrial surface cracks using a Convolutional Neural Network (CNN). It uses Python and TensorFlow/Keras to process images and build a deep learning model for surface crack classification.

The project demonstrates the application of deep learning and computer vision to automated surface inspection.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn

## Dataset

The project uses images of cracked and non-cracked surfaces for training and evaluation.

The dataset is stored separately and is not included in this repository. Make sure the dataset is available in the directory expected by the Python script before running the project.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/sharvari-bhosale/Python-Automation-ML-DL.git
```

### 2. Navigate to the Project Folder

```bash
cd Python-Automation-ML-DL
cd "Deep Learning/CNN-Surface-Crack-Detection"
```

### 3. Create a Virtual Environment

```bash
python -m venv MarvellousCNN
```

### 4. Activate the Virtual Environment

For Windows:

```cmd
MarvellousCNN\Scripts\activate
```

### 5. Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run the Project

Run the following command from the project directory:

```bash
python Marvellous_CNN_Surface_Crack_Detection.py
```

Ensure that the dataset paths and required files are configured correctly in the Python script.
